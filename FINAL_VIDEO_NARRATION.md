# Final Video Narration — Yasmin Voice Tutor

**Target spoken runtime:** about 2 minutes 30 seconds, leaving visual pauses inside the three-minute limit.

## Yasmin opening

Hello. I'm Yasmin.

I'm not a question-answer bot. My job is to teach, listen, notice when understanding breaks, change how I explain, and only claim mastery when the learner proves the idea.

A quick correct answer is not always understanding. So I separate teaching, evaluation, adaptation, evidence, and memory.

## Live learning loop

Let's try fractions.

If a learner tells me, “I don't understand,” I don't repeat the same sentence louder. I change representation.

Now the learner answers, “One half.”

Good evidence — but one answer is not enough.

The learner confirms that two quarters equal one half.

That gives me a second concept check.

Then I ask the learner to explain the idea in their own words.

If the learner only says, “Okay,” I still do not mark mastery.

Agreement is not evidence. I compare the explanation against a concept rubric and can show which evidence is present and what is still missing.

When the learner explains that one half is larger because the same whole is split into fewer equal pieces, the learning loop can complete.

## Memory and planning

Now the important part continues beyond this conversation.

I remember compact mastery evidence, not the child's transcript or voice recording.

That evidence changes what I plan next. If a concept is weak, I repair it. If the evidence is strong, I can introduce new learning. If everything has been seen, I can schedule review.

## Alexa+ / MCP proof

For Alexa+, the same learning runtime is exposed through a real Streamable HTTP MCP server.

An agent can plan a learning session, start it, send learner turns, inspect evidence, and read the compact learner profile through standard tools.

The automated integration test proves that completing one session changes the plan for the next one.

## Close

This hackathon layer is not a disposable demo.

Its evidence-first memory and planning model is designed to move back into the main Yasmin learning app.

Because a useful AI tutor should do more than keep a conversation going.

It should know when learning has actually happened.
